Learning Git

Git Flow:

  • git clone (Clone Remote Repo locally)
  • git checkout - b new branch (Create a new branch locally)
  • git add . (Track changes in local branch)
  • git commit -m "message" (Commit changes)
  • git remote -v (Check origin points)
  • git push (Push committed changes to remote repository)
  • Open a Pull Request on GitHub
  • Merge Pull Request and Delete Branch
